Trademark Classes in India — All 45 Classes Explained

India uses the Nice Classification system for trademark registration. All 45 classes are grouped into 34 classes for goods and 11 classes for services. Choosing the correct class is critical — filing in the wrong class means your brand has no protection in the right market.

How to Choose the Right Trademark Class

Your trademark is only protected in the classes you file under. A clothing brand filing only under Class 25 (clothing) has no protection if a competitor sells bags under Class 18 using the same name.

  • File in every class that covers your current products or services
  • Consider adjacent classes if you plan to expand (e.g., clothing brand also filing Class 35 for retail)
  • Each class requires a separate government fee: ₹4,500 for individuals/MSMEs, ₹9,000 for companies
